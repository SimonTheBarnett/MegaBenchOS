# About MegaBenchOS

[MegaBenchOS](../../README.md) / [Apps](../README.md) / About

The desktop's About page describes MegaBenchOS, shows its release version and credits **Simon The Barnett**. Music and SGDK notices sit below.

“We come from the future, to relive the past”

Open **System > About**. B returns to the desktop; fullscreen has Exit and the held Start+B shortcut.

## Development

[about.c](about.c) reads public system information and redraws when the window or theme changes. See the [SDK](../../sdk/README.md) and [build guide](../../docs/BUILD.md).
