# Creative apps

[MegaBenchOS](../../README.md) / [Apps](../README.md) / Creative apps

- [MegaPaint](megapaint/README.md): draw pixel art, choose colours and save pictures.
- [MegaPad](megapad/README.md): write notes with the on-screen keyboard.

Both use the shared [RAM Disk](../../kernel/storage/README.md). See [picture formats](../../docs/MBP_FORMAT.md) for saved artwork and the [SDK](../../sdk/README.md) for shared editor services.
