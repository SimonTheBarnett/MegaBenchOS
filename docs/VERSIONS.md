## v1.0 - 11 October 2026

The first public release for the Sega Mega Drive / Genesis, made by **Simon The Barnett**.

- Desktop with six folders, five themes, compact windows and a fading boot logo.
- MegaPaint pixel-art editing, MegaPad notes and a shared session-file manager.
- MegaPlayer with five CC0 songs and accessible credits.
- Full-window Snake with a countdown, difficulty progression and sound cues.
- Ocean Dreams, StarDrive, MegaBounce and ColourStorm fullscreen demos.
- Calculator, Sound Test, runtime Clock and System settings.
- Controller and Sega Mouse input, shared app exits and desktop restoration.
- Public C SDK and Windows 11 build/setup guides.

RAM Disk files are session-only. Physical hardware verification is pending. See [downloads](https://github.com/SimonTheBarnett/MegaBenchOS/releases), [testing](testing.md) and [future ideas](../TODO.md).

The release version is defined in [version.h](../inc/version.h); SDK versions are separate. Licensing is described in the [main README](../README.md#licensing).
